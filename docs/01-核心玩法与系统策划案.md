### 1.2 风味与镀金后缀机制（防卡死铁律）
自第 2 章起，烤盘上会出现特殊烘焙格，为滑入、移入或停驻的猫饼附上额外风味属性 `flavor`（共 4 种状态）：
- `plain`（原味，无后缀，默认，`1.00×`）
- `matcha`（宇治抹茶洒粉：绿叶微标，第 2 章引入，匹配加价 **`1.25×`**）
- `berry`（甜心草莓果酱：草莓微标，第 3 章引入，匹配加价 **`1.25×`**）
- `gold`（星光金箔烘焙：金光边框，第 2 章引入，万能风味王牌，任意匹配均享 **`1.35×`**）

#### 规则铁律（核心防卡死设计）：
1. **任意同阶皆可合并**：只要两颗猫饼的阶数 `tier` 相同（且 `tier < 7`、非冰封），**无论它们各自的 `flavor` 是原味、抹茶、草莓还是镀金，都能顺利合成 `tier + 1`！** 绝不出现“因为风味不同而不能合并”的阻塞体验。
2. **合并后风味继承优先级**：两颗同阶猫饼合并生成高一阶猫饼时，新猫饼按以下顺序决定 `flavor`：
   - 若目标格本身是特殊格（`G`/`M`/`B`），先按继承规则取优，再叠加目标格染色（`gold` 不会被 `M/B` 降级覆盖）；
   - 双球合并继承优先级：`gold`（最高，只要任一方是镀金，合成物直接为 `gold`） > **主动移动方（Moving Tile）非原味风味** > **被撞静止方非原味风味** > `plain`。
3. **风味对上菜的匹配规则**：
   - 当顾客订单某槽位要求 **不限风味**（`flavor: 'any'`）时：任意风味的同阶猫饼都能匹配（系统优先消耗 `plain` 普通饼，尽量为玩家保留高价值的特种风味与 `gold` 猫饼）；若消耗了 `gold` 猫饼，该单品仍享受 **`×1.35`** 镀金加价！
   - 当顾客订单某槽位要求 **指定风味**（如 `C4[matcha]` 抹茶蜂蜜布丁）时：仅接受 `flavor === 'matcha'`（享 **`×1.25`** 加价）**或万能王牌 `flavor === 'gold'`**（享 **`×1.35`** 加价）的该阶猫饼；原味或其他风味不能顶替。

## 2. 异形盘格 2048 滑动合成与补料机制

### 2.1 异形盘格类型表
每关烤盘基于 `3×3` 到 `5×5` 的逻辑网格裁剪而成，支持以下 9 种单元格属性（`v0.11.0` 新增 `O` 星炉格与 `S` 蜜糖格，并将第 1 章机制出场前置为 `1-4 抹茶 M → 1-6 镀金 G → 1-8 冰封 I`）：

| 编码 | 格类型 | 出现章节 | 物理与交互行为 |
| :-: | :--- | :---: | :--- |
| `.` | 普通烘焙格 | 全章节 | 可承载猫饼，正常通行与合并 |
| `#` | 缺角 / 虚空 | 全章节 | 不存在物理格位，构成 L 形、十字、缺角星盘等异形边界，**阻断滑动穿行**（仅「挑拣移位叉」可跨障飞越） |
| `X` | 木质障碍柱 | 1-8 起 | 占格实体障碍物，不可放猫饼，**将所在行/列切割为两段各自独立的 2048 滑道** |
| `M` | 抹茶洒粉格 | 1-4 起 | 猫饼停留/挪入 `M` 格或于此合成时，若当前非 `gold`，则染为 `matcha` 风味（`gold` 不会被覆盖降级）；`R15 宇治双爪盘` 解锁提前至 `1-4` |
| `G` | 镀金烘焙格 | 1-6 起 | 猫饼滑经停留在 `G` 格、移位叉挪入 `G` 格或于此合成时，立即获得 `gold` 镀金状态（该格整局永久生效，可反复镀金） |
| `I` | 冰封起始格 | 1-8 起 | 仅在开局生效的冰壳状态（底层仍是 `.` 普通格）。被冰封的猫饼（`frozenHp = 1`）：**不可参与滑动移动、不可被直接合并、不可点击装入托盘**；当其**正上下左右 4 个相邻格中任意格发生一次合成**（包括滑动合成与移位叉跨格合并），或直接对其使用「挑拣移位叉」单点破冰 / 释放蜂蜜柴柴主动技时，冰壳碎裂恢复为普通可操作猫饼（**破冰本身 0 分**，释放的高阶原料即为奖励） |
| `B` | 草莓果酱格 | 2-1 起 | 猫饼停留/挪入 `B` 格或于此合成时，若当前非 `gold`，则染为 `berry` 风味；`2-1` 同步解锁 `R25 草莓小爪碟`（单件 `C3` 草莓，基础价 `188`） |
| `O` | 星炉格（`oven`） | 2-4 起 | 可通行/可合成格位；未冰封且 `< C5` 的猫饼连续停留满 **`6.0s`** 自动升 1 阶（封顶 `C5`）并打上热乎时间戳 `bakedAt`（**严格 0 分**）；滑离、装盘或被冰封时进度重置 |
| `S` | 蜜糖格（`syrup`） | 3-2 起 | 粘滞定位格：滑入 `S` 格的猫饼立即停驻在此格（同阶可在此合并）；而**原本就停在 `S` 格上的猫饼**在下次滑动时可正常滑离，用于精控中段卡位与合成路线 |

### 2.2 四向滑动规则（异形分段 2048）
玩家在烤盘区域向上、下、左、右滑动（或桌面端按下方向键 / WASD）：
1. **分段扫描**：沿滑动反方向逐行或逐列扫描，遇到 `#` 缺角、障碍柱 `X` 或当前仍处于 `frozenHp > 0` 的冰封格时，视为**硬墙断点**，将该行/列切分成若干连续普通格片段。
2. **单段压缩与合并（经典 2048 单步防连合规则）**：
   - 在每个连续片段内，所有非空且未冰封的猫饼向滑动方向紧缩（遇到 `S` 蜜糖格时滑入停驻）；
   - 从靠墙端开始依次比较相邻两颗猫饼：若 `tier` 相同且 `tier < 7`，则合并为一颗 `tier + 1` 的新猫饼，并标记本步已合并；**同一颗新合出的猫饼在本轮滑动中不再继续与下一颗同阶连续合并**（例如 `[C1, C1, C2]` 左滑结果为 `[C2, C2]`；`[C1, C1, C1, C1]` 左滑结果为 `[C2, C2]`）。
3. **有效滑动判定与自动刷饼**：
   - 若本次滑动导致至少 1 颗猫饼位置发生变化，或发生至少 1 次合成，则判定为**有效滑动**；
   - **每次有效滑动完成后**：系统立即从当前所有**空白可用格（`.`/`G`/`M`/`B`/`O`/`S` 且无猫饼）**中均匀随机挑选 `1` 格，生成 `1` 颗低阶猫饼（基础 `90%` 为 `C1`，`10%` 为 `C2`；受「精选猫饼粉」设备与「眠眠星兔」被动提高 `C2` 比例，最高可达 `43%`）；
   - 若新生成的猫饼恰好落在了 `G`/`M`/`B` 特殊格上，立即自动染色。
   - **无效滑动**：若盘格内没有任何一颗猫饼能移动或合并，视为无效滑动，播放轻柔撞墙闷响并微颤提示，**不刷出新猫饼**。
4. **合成的纯正向价值**：每次合成产生 Q 弹光效、正交 4 邻接冰封格破冰（若触发），并且合出 **`≥ C5` 猫饼**时额外回复主厨搭档 **`+8%` 主动技充能**；但**所有合成均严格计 0 分**。

### 2.3 底部独立「揉面补料」按钮
在烤盘正下方居中放置超大视觉焦点按钮——**「🐾 揉面补料」**：
- **交互**：极短防抖冷却（`0.12s`），玩家在营业倒计时内随时可以点击（或按 `Space`）；
- **效果**：在当前盘格所有空白可用格中随机挑选 `1` 格，投放 `1` 颗低阶猫饼（与滑动刷新同分布：`C1` / `C2`，若落入特殊格同样立即染色，`0` 分）；
- **战略意义**：
  1. **急单救火**：顾客只要 1 颗 `C1` 或只差 1 颗低阶饼凑成套餐时，无需打乱已经排好的大饼阵型去滑动，直接点「补料」瞬间出原料上菜；
  2. **主动压盘博弈**：想快速攒大饼冲 VIP 单时连续补料+滑动，但过快补料会迅速挤占异形盘格空间，迫使玩家必须及时通过托盘上菜消格！
- **满格状态**：若当前盘格已无任何空格，点击「补料」轻弹提示“烤盘已满，请先上菜或合成腾格！”。

### 2.4 `v0.10` 局内深度：烘焙暴击、面团温度、出炉新鲜度与热潮 V2
> 全部数值位于 `src/balance_config.js`（`BAKE_CRIT` / `DOUGH_TEMP` / `FRESH` / `FEVER_V2`），各自受 `FEATURES` 开关保护；**合成与暴击仍严格 0 分**，只产出资源。

1. **烘焙暴击（`bakeCrit`）**：单次有效滑动同时合出 **≥ 2 颗 `C3+`** 即触发——
   - 2 颗「双重烘焙！」：热潮能量 `+8`、搭档技能 `+6%`；
   - 3 颗「三重烘焙！」：热潮 `+15`、技能 `+10%`、本次合出的最高阶新饼**镀金**；
   - 4 颗及以上「星光暴击！」：热潮 `+25`、技能 `+15%`、该饼镀金并再 **升 1 阶**（不超过 `C7`）。
   - 表现：金色扩散环、轻微震屏、叠层风铃音效与短震动；热潮激活期间暴击不再充能热潮。
2. **面团温度（`doughTemp`）**：每次揉面 `+22°`，温度按 `temp·e^(−0.8·dt) − 2·dt` 自然冷却——
   - **冷区（`< 40`）**：基础 `C1/C2` 分布；
   - **金色温区（`40 ~ 99`）**：`C2` 概率额外 `+15%`；连续 `6` 次温区揉面保底 `1` 颗 `C3`（风味关优先落抹茶/草莓）；
   - **过热（`≥ 100`）**：本次只出 `C1`，按钮锁定 **`1.2s`**（连败保底局缩短为 `0.6s`），解锁后温度回到 `50`。
   - 节奏：`0.35 ~ 0.5s` 一下稳定停在温区，`0.12s` 狂点约 `0.6s` 过热。揉面按钮下方显示温度条，锁定时文案为「过热中」。
3. **出炉新鲜度（`freshBonus`）**：合成产生的 `C2+` 猫饼带 `bakedAt` 时间戳，**`6s` 内**端给顾客时单品价 **`×1.15`**（品质区）并冒热气；整单全部热乎额外 `+6` 热潮能量，弹出「热乎！」。
4. **星光热潮 V2（`feverV2`）**：
   - 场面区加成由 `+25%` 调整为 **`+20%`**，耐心流逝减半不变；
   - 热潮中滑动可 **连锁合成**（同一次滑动最多 `3` 轮）、揉面改为「热潮揉面」：`70% C2 / 30% C3`，且不改变面团温度；
   - 热潮中每次上菜延长 `+1s`（单次热潮累计上限 `+4s`）；
   - 热潮结束「余温」：盘面所有非冰封 `C1` 升为 `C2`。

### 2.5 `v0.11` 关卡目标、局内随机事件与结算诊断（方向 C）
> 由 `src/level_goals.js`、`src/level_events.js` 与 `src/run_diagnostics.js` 实现，受 `FEATURES.goals / FEATURES.events` 控制。

1. **7 种关卡目标（30 关中 14 关为目标关，与 16 关经典刷分关交替）**：
   - `score`（默认刷分）、`ice_clear`（清冰：`1-8 / 3-3 / 3-8`）、`centerpiece`（献上 `C5+/C6+` 招牌大单：`1-10 / 2-10 / 3-10`）、`serve_count`（上菜数：`1-5 / 2-5`）、`combo`（连击：`1-7 / 2-7`）、`hot_serve`（整单热乎：`2-3 / 2-9`）、`limited_knead`（限次揉面解谜：`3-4 / 3-7`）。
   - **过关门控与星级分离**：目标未达标时即使分数超 1★ 亦判 `0★ / cleared=false`；达标后仍按分数评 `1~3★`，保护 18/40★ 章节门控与星尘经济。
   - **提前打烊（`earlyClose`）**：目标完成后当 `ordersServed >= 1`、`elapsedSec >= 3` 且 `score + round(timeLeft * 40 * chFactor) >= star3` 时立即提前打烊，剩余时间奖励计入结算 `earlyCloseBonus`（单局上限 `20,000`，云函数单独校验，不污染局内上菜分），避免速通玩家被提前踢出在 1★ 而无法冲 3★。
2. **5 种局内随机事件（由 `events` 种子流在 25%~75% 营业段调度 1~3 个，同时最多激活 1 个）**：
   - **美食家巡店（`critic_visit`）**：15s 内下一单场面区 `+0.50`（1-5 起）；
   - **原料特价（`flour_sale`）**：接下来 5 次揉面必出 `C2`（1-3 起）；
   - **热风烤盘（`hot_oven`）**：8s 内热乎有效时间翻倍至 `12s`（第 2 章起）；
   - **冰霜降临（`frost_snap`）**：预警 3s 后随机冻住 2 块优先 `≤ C5` 猫饼（第 3 章起）；
   - **外卖快送（`delivery_rush`）**：下 1 位顾客换成限时外卖单（耐心 `×0.7`、赏金 `×1.4`，第 2 章起）。
3. **结算诊断（`RunDiagnostics`）**：结算弹窗展示本局亮点（暴击次数、整单热乎率、热潮次数）并按优先级给出 1 条可落地中文改进建议。

## 3. 配餐托盘（3~4 格）、厨余篮冷却与零死锁闭环

### 3.1 盘格 → 托盘的单向装盘规则
在吧台顾客区与异形烤盘之间，横置一条**「配餐托盘（Serving Tray）」**，初始拥有 **`3` 个托盘槽**（在吃茶小铺升级「宽大木托盘」Lv.1 后扩充至 **`4` 个托盘槽**）：
1. **需求实时高亮**：系统实时扫描场上所有在座顾客的未完成菜单需求，凡是烤盘内存在**满足任一位在座顾客当前需求**的非冰封猫饼，该猫饼外圈自动亮起**暖金呼吸提示圈**。
2. **单击装盘消格**：
   - 在烤盘上**轻点（单击）**任意一颗非冰封猫饼：若配餐托盘仍有空槽，该猫饼**立刻从异形盘格中移除（瞬间腾出一个烤盘空格）**，以 `0.16s` 轻快弧线飞入托盘最左侧空槽；

### 4.4 全局唯一铁律：纯上菜得分公式（`v0.9.0`）
> **铁律**：`orderState.score` 仅能在 **“顾客整单上齐结账”** 这唯一入口增加。以下行为**严格计 0 分**：四向滑动合并、点击揉面补料、破冰、单击猫饼装入托盘、双击丢进厨余篮、使用挑拣移位叉（挪移/互换/跨格合并/破冰/直投厨余）、使用升阶魔法勺、释放搭档主动技。

```text
单次上菜得分 = round(
    Σ(单品基础菜价(tier, catcakeUpgradeLv) × 单品风味镀金倍率)
  × 套餐组合倍率       // 1品=1.00 | 2品=1.12 | 3品=1.25
  × 耐心小费倍率       // 绿(>60%)=1.20 | 黄(25%~60%)=1.00 | 红(<25%)=0.80
  × 上菜连击倍率       // 8.0s窗: 1连=1.00 | 2连=1.06 | 3连=1.13 | 4连=1.20 | 5连+=1.28
  × 顾客类型倍率       // 普通=1.00 | 焦糖小狐狸=1.25 | 星冠美食家VIP=1.50
  × 搭档与设备杂项加成 // 小蜜柑被动(×1.08)、星兔爆发(×1.50)、柴柴>=3连(连击项+0.10)、宽托盘Lv2 3品(×1.12)
  × 热潮倍率           // 非热潮=1.00 | 星光热潮=1.25
)
```
- **单品风味镀金倍率**：
  - `gold` 镀金猫饼：**`1.35`**（即使该槽位不限风味也享 `1.35×` 溢价）；
  - 当订单指定风味（`matcha` 或 `berry`）且匹配成功：**`1.25`**；
  - 其余普通匹配：**`1.00`**。
