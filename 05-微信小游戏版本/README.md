# 星夜吃茶 · 喵呜甜品合合乐 (微信小游戏原生版本 + 微信云开发)

本目录为 **原生 Canvas 2D 微信小游戏 (`compileType: "game"`)** 工程，零 HTML/DOM/CSS 依赖、零第三方引擎冗余体积，采用 **微信云开发 (`wx.cloud`)** 实现纯微信生态后端，无需自建服务器或购买域名：

- **5 幕肉鸽主厨闯关 + 90 秒弹射狂欢 + 悠闲经典**：16 件烘焙秘方（4 大流派 2/3 件共鸣）、6 种原料改造、第 2~5 幕场地机关（分流隔板 / 焦糖旋转环 / 冰封甜品 / 评委急单）与无尽午夜加时赛。
- **静默 OpenID 云端存档 + 本地双保险 (`src/save_sync.js`)**：进入游戏无需弹窗，自动通过云函数获取微信 `OPENID` 拉取并单调无损合并进度（最高分取最大、解锁项取并集、永久星尘按 `累计获取 - 已消费` 精确核算），未开通云开发前 100% 自动降级本地流畅运行。
- **单局断点续玩**：打到第 2~5 幕或幕间整备间中途退出/切后台，重进大厅自动展示 **「继续第 X 幕营业」+「新开一局」** 双按钮，完整还原罐内甜品、秘方构筑、订单与整备间货架。
- **合规自愿授权「店长名片」+ 全服店长排行榜**：零启动强弹授权；在「营业履历」弹窗顶部提供自愿点击的原生透明 `wx.createUserInfoButton` 授权名片，并内置 **主厨闯关榜 / 90 秒狂欢榜** Top 50 全服实时排行与我的排名。
- **极简包体**：全量量化美术资源 + 代码远低于微信小游戏 **4 MB** 主包上限（`cloudfunctions/` 上传至微信云端，不占用客户端包体）。

## 一、如何导入并立即试玩

1. 下载并打开官方 **[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)**（稳定版）。
2. 选择 **「小游戏」→「导入项目」**：
   - **项目目录**：选择本仓库下的 `05-微信小游戏版本` 目录（含 `game.json`、`project.config.json` 与 `cloudfunctions/`）。
   - **AppID**：填入你在 [微信公众平台](https://mp.weixin.qq.com/) 注册的小游戏 **正式 AppID**（注：云开发需要真实 AppID，游客号 `touristappid` 无法开通云开发，但仍可本地正常试玩全部玩法）。

## 二、微信云开发（云存档 / 全服排行榜）3 步开通与部署指南

还没有开通微信云开发？按以下 3 步在 **微信开发者工具** 内点几下鼠标即可完成（含免费额度，0 服务器运维）：

### 第 1 步：一键开通云开发环境（约 1 分钟）
1. 用你的小游戏 **正式 AppID** 导入 `05-微信小游戏版本` 后，点击微信开发者工具顶部工具栏的 **「云开发」** 按钮。
2. 在弹出的窗口点击 **「开通」**，同意协议：
   - **环境名称**：随意填写（例如 `hoshi-prod`）。
   - **计费方式**：选择 **「按量付费」** 或 **「新用户免费套餐 / 基础版」**（微信云开发自带免费调用与数据库额度，个人小游戏日常使用基本 0 成本）。
3. 等待数十秒初始化完成后，进入「云开发控制台」，在右上角复制你的 **环境 ID**（形如 `cloud1-xxxxxx`）。

### 第 2 步：核对已预填的云环境 ID（已配置完成）
- [`src/cloud_config.js`](src/cloud_config.js) 与 [`cloudbaserc.json`](cloudbaserc.json) 已预先绑定环境 ID `dev-d0ggz3zx89d349af3`：
  ```js
  module.exports = {
    CLOUD_ENV_ID: 'dev-d0ggz3zx89d349af3',
    CLOUD_FUNCTION_NAME: 'kissa_sync',
    ENABLE_CLOUD_SYNC: true,
    SYNC_DEBOUNCE_MS: 1800
  };
  ```

### 第 3 步：右键上传并部署云函数 `kissa_sync`
1. 在微信开发者工具左侧目录树中，展开 `cloudfunctions` 文件夹，你会看到带有云朵图标的 **`kissa_sync`** 目录。
   > 若未显示云朵图标：右键 `cloudfunctions` 目录 → 选择当前云开发环境即可。
2. **右键点击 `kissa_sync` 文件夹** → 选择 **「上传并部署：云端安装依赖（不上传 node_modules）」**。
3. 等待底部状态栏提示「上传部署成功」（首次调用时，云函数会自动在云数据库中创建 `players` 集合，无需手动建表！）。
4. 点击工具栏「编译」刷新模拟器：大厅左上角星尘旁显示 **`☁️已云存`**，即代表微信云存档、跨设备断点续玩与全服店长排行榜已全部激活！

## 三、上线提审前的《用户隐私保护指引》勾选提示

为了让真机玩家点击「营业履历 → 微信授权名片」时能正常弹出微信昵称头像授权框并通过微信审核，提审前请登录 **[微信公众平台](https://mp.weixin.qq.com/)**：
1. 进入左侧菜单 **「设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引」** 点击更新。
2. 点击「增加信息类型」，勾选 **「用户信息（微信昵称、头像）」**，用途填写：**「用于在店长名片及全服排行榜中展示玩家昵称与头像」**，保存提交即可。

## 四、目录结构

```text
05-微信小游戏版本/
├── game.json                   # 小游戏竖屏与设备方向配置
├── project.config.json         # 微信开发者工具工程配置 (含 cloudfunctionRoot)
├── game.js                     # 小游戏启动入口
├── cloudfunctions/
│   └── kissa_sync/             # 微信云开发云函数（自动建表 + 云存档合并 + 名片同步 + 全服榜）
│       ├── index.js
│       ├── package.json
│       └── config.json
├── assets/                     # 量化手绘美术与 UI 图集资源
└── src/
    ├── cloud_config.js         # 微信云开发环境 ID 与同步开关配置
    ├── save_sync.js            # 存档迁移、单调无损合并算法与单局断点快照序列化
    ├── platform.js             # wx.* / wx.cloud / wx.createUserInfoButton 与浏览器降级抽象层
    ├── constants.js            # 甜品阶梯、UI 图集坐标、秘方共鸣、机关与成就配置
    ├── physics_shapes.js       # 多边形碰撞体轮廓定义
    ├── physics.js              # SAT + Sequential Impulse 刚体物理引擎
    ├── audio.js                # 原生 WebAudio 程序化配乐与音效
    ├── ui_draw.js              # 统一绘本风卡片 / 标签 / 货币胶囊 / 图集图标绘制原语
    ├── jar_renderer.js         # 玻璃罐、中央定角炮台、弹壁预测线与粒子特效渲染
    ├── screens_ui.js           # 大厅（含云状态胶囊、断点续玩双按钮）与局内 HUD
    ├── modals_ui.js            # 店长名片与全服排行榜 / 小铺 / 新手指引 / 整备间 / 结算弹窗
    └── game_app.js             # 核心玩法、云同步调度、断点恢复与输入状态机
```
