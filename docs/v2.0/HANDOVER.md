# 《一起做猫饼》(v2.0) 工程重构交接文档

## 1. 概述与背景
本项目为微信小游戏《一起做猫饼》（原《星猫烘焙屋》/《星猫点心屋》）的 2.0 玩法重构工程。
- **分支名称**：`gameplay_redesign_dessert_service`
- **重构核心**：由原 60 秒狂欢及掉落物理合成玩法，重构为类似《飞机大厨》式顾客不断点单、通过异形盘格滑动合成（2048机制）升级猫样甜点（“猫饼”）、配餐托盘组装上菜、且**仅上菜得分**的关卡制经营策略玩法。

## 3. 素材与工具链现状

### 3.1 资产切图管线
- **处理脚本**：`scripts/extract_assets.py` 已升级支持 `--v2` 模式及 `--verify-out` 参数。
- **功能特性**：
  - 自动将 4x2 拼版图智能切分去背、消除溢色、裁切并归一化输出为统一透明 PNG。
  - 支持输出 14 张猫饼单图（普通态/烘焙态）、两张图集（顾客图集 `customers_atlas.png`、棋盘图集 `board_tiles_atlas.png`）及主视觉插画 `title_hero_v2.jpg`。
  - 支持生成深色棋盘 QA 接触表供视觉验收。

### 3.2 视觉素材状态
- 4 张 4x2 拼版生图 Prompt 与 1 张主视觉 Prompt 已在 `04-美术与音频素材制作规范.md` 中完备定义。
- 当前待美术团队提供或后续 AI 生图服务恢复时批量生成原图，随后运行 `python scripts/extract_assets.py --v2` 即可一键产出全部游戏资产。

1. **底层引擎实现**：
   - 在 `05-微信小游戏版本/src/gameplay/` 下实现 `grid_engine.js`（异形盘格 2048 滑动合成与特殊格行为）与 `order_service.js`（顾客生成、耐性计时、配餐验证与计分）。
