> **文档定位与版本命名说明**：本文档定义《一起做猫饼》自 `v0.8.0` 重构基线至 **`v0.9.0`** 阶段所有保留与新增资产的视觉风格、尺寸规格、AI 拼版生图 Prompt、`extract_assets.py` 切图流水线配置、微信小游戏包体预算以及 Web Audio 纯合成音效表。（注：资产文件名 `title_hero_v2.jpg`、`v2_*_sheet.jpg` 及脚本参数 `--v2` 中的 `v2` 代表“第 2 代核心玩法美术管线”，属于固定技术文件标识，保持不变。）

## 1. 核心美术风格铁律（沿用现行绘本风）

为确保 `v0.8.0` 重构新增猫饼、顾客与现存木屋场景 `bakery_bg.jpg`、主厨立绘 `chef_mikan.png` / `patron_luna.png` / `patron_mugi.png` 以及 3 张 `ui_atlas` 保持 **100% 视觉无缝融合**：
- **线条语言**：统一采用**温暖深咖啡棕粗描边（`#4A2C2A`）**，禁止使用纯黑 `#000000` 锐利生硬外轮廓。
- **上色技法**：日系手绘水彩厚涂绘本风（Soft Watercolor & Gouache Storybook），表面带微微焦糖烘焙质感、柔和暖黄高光与糖粉颗粒。
- **构图留白**：所有独立角色与猫饼精灵四周保留 **`8%~10%` 透明安全边距**，避免旋转或 Q 弹缩放动画时边缘裁切；微缩展示至 `48px` 烤盘格内时依然清晰可辨。

## 6. Web Audio 纯程序化音效清单（零包体占用）

沿用 `05-微信小游戏版本/src/audio.js` 的 C 大调全纯 Web Audio API 合成架构（含现有双音轨 BGM《星夜圆舞曲 · 3/4》与《午夜吃茶波萨 · 4/4》，以及热潮/弹窗柔化滤镜）：

### 6.1 直接复用的现有方法（来自 `src/audio.js`）
- `playStartCafe()`：点击进入营业关卡时的木门风铃。
- `playMerge(tier, combo, isCrit)`：2048 合成成功，随猫饼阶数 `C2~C7` 自动升高音调。
- `playServeBell()` & `playOrderComplete()`：托盘凑齐套餐端给顾客上菜结账清脆铜铃 + 凯旋和弦。
- `playIceShatter()`：冰封格被邻近合成震碎的晶莹玻璃碎裂音。
- `playShopBuy()` & `playPatronSelect()`：吃茶小铺消费与切换主厨搭档音效。
- `playChefSkill(patronId)`：释放小蜜柑 / 眠眠星兔 / 蜂蜜柴柴主动技的专属短旋律。
- `playTool(kind)`：使用 `fork`（挑拣移位叉：挪移/互换/跨格合并/破冰）/ `spoon`（升阶魔法勺）音效。
- `playFeverStart()`：开启星光热潮。
- `playRushTick(urgent)`：营业倒计时最后 `5s` 的轻柔木鱼提示。
- `playShiftClear()` & `playGameOver()`：分别用于过关星级结算凯旋音与未达标打烊遗憾音。

### 7.3 免费可商用圆体字体子集化流程（`kissa_round.ttf`）
- **源字体**：`ResourceHanRoundedCN-Bold.ttf`（资源圆体 Bold，SIL OFL 1.1 免费可商用，原体积 `13,650.9 KB`）。
- **裁剪脚本**：[`scripts/build_font_subset.py`](../scripts/build_font_subset.py) 自动扫描 `05-微信小游戏版本/src/` 全部 14 个 JS 文件中的静态文案、数字与全半角标点，提取 **924 个唯一字符（含 790 个汉字）**，调用 `fontTools.subset`（`--layout-features=* --no-hinting --desubroutinize`）生成 **`05-微信小游戏版本/assets/fonts/kissa_round.ttf`**。
- **裁剪结果**：`13,650.9 KB → 367.7 KB`（体积减少 **`97.3%`**），具备标准 TrueType `00 01 00 00` 文件头，运行时由 `game.js` 入口调用 `UI.initGameFont('assets/fonts/kissa_round.ttf')` 加载。
