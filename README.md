# 一起做猫饼（原：星夜吃茶）

本仓库为 **微信小游戏原生 Canvas 2D 版本** 工程（已移除早期 H5 工程、单文件 HTML 构建与旧版 2D 物理玻璃罐代码）。

## 版本演进与文档导航

> **版本号规范说明（上线前 SemVer 归正）**：游戏尚未正式公测上线，全项目统一采用 **`0.x.y`（上线前研发序列）→ `v1.0.0`（微信正式首发版）** 体系（此前内部文档曾混用的 `2.0 / 3.0 / 4.0 / 4.1` 已统一归正；代码内的 `schemaVersion: 2` 仅作为存档数据结构代数标识）：
> - **`v0.1.0 ~ v0.4.0`**：早期物理玻璃罐合成原型阶段（已淘汰并归档至 `docs/archive/`）
> - **`v0.8.0`（现行代码基线）**：完成 **异形盘格 2048 滑动搓猫饼 × 独立补料 × 配餐托盘组合上菜（上菜唯一得分）× 《飞机大厨》式 3 大章节 30 关** 核心重构
> - **`v0.9.0`（当前调整目标版 · 待代码落地）**：**内测经济平衡与厨具机制精修版**（收紧星尘与乘区膨胀、重塑「挑拣移位叉」、新增厨余篮 `8s` 冷却与长线章节扩展加固）
> - **`v1.0.0`（规划首发版）**：微信小游戏首次正式提审上线版本（后续新章节与新玩法按 `v1.1.0+` 递增）

## 自动上传微信开发者平台 (GitHub Actions CI)

每次推送到 `main` 分支（或手动在 GitHub Actions 点击 **Run workflow**），都会先运行单测与完整 E2E 检查，再通过官方 `miniprogram-ci` 自动上传至微信开发者平台（注：未正式上线前内测构建版本号规范为 `0.9.<run_number>`，首次正式提审首发锁定为 `1.0.0`，待 `v0.9.0` 代码阶段同步更新上传脚本）：

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → **开发管理** → **开发设置** → **小程序代码上传**：
   - 生成并下载 **小程序代码上传密钥**（`.key` 文件内容）
   - 将 **代码上传 IP 白名单** 关闭（GitHub Actions 云端运行机出口 IP 不固定）
2. 打开本 GitHub 仓库 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**：
   - `WECHAT_PRIVATE_KEY`：完整粘贴 `.key` 私钥文本内容（包含 `-----BEGIN RSA PRIVATE KEY-----` 到结尾）
   - `WECHAT_APPID`（可选）：如未设置，默认读取 `05-微信小游戏版本/project.config.json` 中的 `appid`（当前为 `wx923bf8440b65a1af`）
