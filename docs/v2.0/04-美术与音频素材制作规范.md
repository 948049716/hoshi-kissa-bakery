# 一起做猫饼 2.0 — 美术与音频素材制作规范

> **文档定位**：本文档定义 2.0 版本所有新增与保留资产的视觉风格、尺寸规格、AI 拼版生图 Prompt、`extract_assets.py` 切图流水线配置、微信小游戏包体体积预算以及 Web Audio 纯合成音效表。

## 1. 核心美术风格铁律（沿用现行绘本风）

为确保 2.0 新增猫饼、顾客与现存木屋场景 `bakery_bg.jpg`、主厨立绘 `chef_mikan.png` / `patron_luna.png` / `patron_mugi.png` 以及 3 张 `ui_atlas` 保持 **100% 视觉无缝融合**：
- **线条语言**：统一采用**温暖深咖啡棕粗描边（`#4A2C2A`）**，禁止使用纯黑 `#000000` 锐利生硬外轮廓。
- **上色技法**：日系手绘水彩厚涂绘本风（Soft Watercolor & Gouache Storybook），表面带微微焦糖烘焙质感、柔和暖黄高光与糖粉颗粒。
- **构图留白**：所有独立角色与猫饼精灵四周保留 **`8%~10%` 透明安全边距**，避免旋转或 Q 弹缩放动画时边缘裁切；微缩展示至 `48px` 烤盘格内时依然清晰可辨。

## 6. Web Audio 纯程序化音效清单（零包体占用）

沿用 `05-微信小游戏版本/src/audio.js` 的 C 大调全纯 Web Audio API 合成架构（含现有双音轨 BGM《星夜圆舞曲 · 3/4》与《午夜吃茶波萨 · 4/4》，以及热潮/弹窗柔化滤镜）：

### 6.1 直接复用的现有方法（来自 `src/audio.js`）
- `playStartCafe()`：点击进入营业关卡时的木门风铃。
- `playMerge(tier, combo, isCrit)`：2048 合成成功，随猫饼阶数 `C2~C7` 自动升高音调。
- `playServeBell()` & `playOrderComplete()`：托盘凑齐套餐端给顾客上菜结账清脆铜铃 + 凯旋和弦。
- `playIceShatter()`：冰封格被邻近合成震碎的晶莹玻璃碎裂音。
- `playShopBuy()` & `playPatronSelect()`：吃茶小铺消费与切换主厨搭档音效。
- `playChefSkill(patronId)`：释放小蜜柑 / 眠眠星兔 / 蜂蜜柴柴主动技的专属短旋律。
- `playTool(kind)`：使用 `fork`（清格叉）/ `spoon`（升阶勺）音效。
- `playFeverStart()`：开启星光热潮。
- `playRushTick(urgent)`：营业倒计时最后 `5s` 的轻柔木鱼提示。
- `playShiftClear()` & `playGameOver()`：分别用于过关星级结算凯旋音与未达标打烊遗憾音。

### 6.2 需在 `src/audio.js` 增量新增的 7 个 2.0 专属音效
| 新增方法名 | 触发时机 | 合成音色设计（C 大调） |
| :--- | :--- | :--- |
| `playGridSlide()` | 四向有效滑动 | 轻盈柔滑的木盘擦拭滑音（短促带通滤波粉噪 + 轻三角波上滑 `330Hz → 440Hz`，`55ms`） |
| `playGridBlocked()` | 无效滑动撞墙 | 低沉温润的敲木头闷响（`165Hz → 110Hz` 正弦衰减，`65ms`） |
| `playKneadSpawn()` | 点击「揉面补料」/ 自动刷饼 | 软弹糯米面团落盘的“噗叽”气泡音（`420Hz → 620Hz` 快速弹性正弦，`50ms`） |
| `playTrayPlace()` | 单击猫饼装入托盘槽 | 清脆瓷碟轻放声（`880Hz` 与 `1318Hz` 极短双正弦叮声，`70ms`） |
| `playTrayTrash()` | 双击托盘猫饼丢进厨余桶 | 下行滑落音（`587Hz → 261Hz` 三角波快速衰减，`95ms`） |
| `playCustomerAngry()` | 顾客耐心归零生气离开 | 委屈两连下行喵呜滑音（`523Hz → 392Hz` 锯齿柔滤波，`180ms`） |
| `playStarUnlock(starIndex)` | 局内进度条或结算点亮 1/2/3 星 | 随 `starIndex`（1/2/3）递增的三连大调高音竖琴璀璨音（`C6 / E6 / G6`） |
