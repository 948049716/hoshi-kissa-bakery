# 一起做猫饼 (微信小游戏原生版本 + 微信云开发)

> **当前产品版本**：现行已落地基线 **`v0.9.0`**（内测经济平衡、厨具机制精修与全量绘本 UI 重构版），首次正式提审首发目标版本为 **`v1.0.0`**。详见 [`../docs/v0.9.0-版本调整计划书.md`](../docs/v0.9.0-版本调整计划书.md)。

本目录为 **原生 Canvas 2D 微信小游戏 (`compileType: "game"`)** 工程，零 HTML/DOM/CSS 依赖、零第三方引擎冗余体积，采用 **微信云开发 (`wx.cloud`)** 实现纯微信生态后端，无需自建服务器或购买域名：

- **异形盘格 2048 搓猫饼 × 3 席实时出餐闯关**：3 大章节 × 10 关 = **30 关手绘选关地图**，7 阶纯猫造型甜点（`C1~C7`）、4 种烘焙风味（原味 / 宇治抹茶 / 甜心草莓 / 星光金箔）、8 位星夜动物顾客（24 道组合套餐）与 **“纯上菜唯一得分”** 核心法则。
- **后厨双轨生料 × 配餐托盘 × 策略厨具**：四向滑动合成自动刷料 + 独立「🐾 揉面补料」主动压盘，单击装入 `3~4` 格配餐托盘自动凑单上菜，配合 3 位主厨搭档（小蜜柑 / 眠眠星兔 / 蜂蜜柴柴）主动技与应急厨具（`v0.9.0` 升级为挑拣移位叉 + 升阶魔法勺 + 厨余篮冷却机制）。
- **静默 OpenID 云端存档 + 本地双保险 (`src/save_sync.js`)**：进入游戏无需强制弹窗，自动通过云函数获取微信 `OPENID` 拉取并单调无损合并进度（存档内部结构代数 `schemaVersion: 2`，含早期 `v0.4.x` 老存档 100% 星尘无损退还迁移，严格执行 `bankStardust = totalEarnedStardust - spent` 守恒），未开通云开发时 100% 自动降级本地流畅运行。
- **合规自愿授权「店长名片」+ 全服双排行榜**：零启动强弹授权；在「星夜营业榜」弹窗顶部提供自愿点击的原生透明 `wx.createUserInfoButton` 授权名片，内置 **总星数进度榜（`stars`）** 与 **星夜累计营业榜（`score`）** Top 50 全服实时排行与我的排名。
- **极简包体**：`assets/ui_v090/` 69 张微信白名单纯 ASCII PNG/JPG 绘本资产 + `assets/fonts/kissa_round.ttf` 裁剪圆体字体 + 纯程序化 Web Audio 合成配乐音效，客户端编译后主包体积约 **`~2.3 MB`**（源码+资产未压缩约 `2.0 MB`），远低于微信小游戏 **4 MB** 主包上限（`cloudfunctions/` 上传至微信云端，不占用客户端包体）。

## 一、如何导入并立即试玩

1. 下载并打开官方 **[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)**（稳定版）。
2. 选择 **「小游戏」→「导入项目」**：
   - **项目目录**：选择本仓库下的 `05-微信小游戏版本` 目录（含 `game.json`、`project.config.json` 与 `cloudfunctions/`）。
   - **AppID**：填入你在 [微信公众平台](https://mp.weixin.qq.com/) 注册的小游戏 **正式 AppID**（注：云开发需要真实 AppID，游客号 `touristappid` 无法开通云开发，但仍可本地正常试玩全部 30 关与吃茶小铺）。

## 二、微信云开发（云存档 / 全服双排行榜）3 步开通与部署指南

按以下 3 步在 **微信开发者工具** 内即可完成云后端部署（含免费额度，0 服务器运维）：

### 第 1 步：一键开通云开发环境（约 1 分钟）
1. 用你的小游戏 **正式 AppID** 导入 `05-微信小游戏版本` 后，点击微信开发者工具顶部工具栏的 **「云开发」** 按钮。
2. 在弹出的窗口点击 **「开通」**，同意协议：
   - **环境名称**：随意填写（例如 `hoshi-prod`）。
   - **计费方式**：选择 **「按量付费」** 或 **「新用户免费套餐 / 基础版」**。
3. 等待初始化完成后，进入「云开发控制台」，在右上角确认你的 **环境 ID**。

### 第 2 步：核对已预填的云环境 ID
- [`src/cloud_config.js`](src/cloud_config.js) 与 [`cloudbaserc.json`](cloudbaserc.json) 已预先绑定环境 ID `dev-d0ggz3zx89d349af3`：
  ```js
  module.exports = {
    CLOUD_ENV_ID: 'dev-d0ggz3zx89d349af3',
    CLOUD_FUNCTION_NAME: 'kissa_sync',
    ENABLE_CLOUD_SYNC: true,
    SYNC_DEBOUNCE_MS: 1800
  };
  ```

### 第 3 步：右键上传并部署云函数 `kissa_sync`
1. 在微信开发者工具左侧目录树中，展开 `cloudfunctions` 文件夹，找到带有云朵图标的 **`kissa_sync`** 目录。
   > 若未显示云朵图标：右键 `cloudfunctions` 目录 → 选择当前云开发环境即可。
2. **右键点击 `kissa_sync` 文件夹** → 选择 **「上传并部署：云端安装依赖（不上传 node_modules）」**。
3. 等待底部状态栏提示「上传部署成功」（首次调用时，云函数会自动在云数据库中创建集合，无需手动建表）。
4. 点击工具栏「编译」刷新模拟器：大厅顶部云状态胶囊显示已同步状态，即代表微信云存档、跨设备进度合并与全服双排行榜已全部激活！

## 三、正式上线（`v1.0.0`）提审前的《用户隐私保护指引》勾选提示

为了让真机玩家点击「星夜营业榜 → 微信授权名片」时能正常弹出微信昵称头像授权框并通过微信审核，提审前请登录 **[微信公众平台](https://mp.weixin.qq.com/)**：
1. 进入左侧菜单 **「设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引」** 点击更新。
2. 点击「增加信息类型」，勾选 **「用户信息（微信昵称、头像）」**，用途填写：**「用于在店长名片及全服排行榜中展示玩家昵称与头像」**，保存提交即可。
