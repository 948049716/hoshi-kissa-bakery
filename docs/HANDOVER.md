# 《一起做猫饼》工程重构与 `v0.9.0` 演进交接文档

## 1. 概述与版本号归正说明
本项目为微信小游戏 **《一起做猫饼》**（原早期探索名《星夜吃茶》）原生 Canvas 2D 工程。
- **标准版本号序列（上线前 SemVer 归正）**：
  - `v0.1.0 ~ v0.4.0`：早期物理玻璃罐合成原型（历史归档，原内部草稿曾误标 `v1 / 3.0 / 4.0 / 4.1`）；
  - **`v0.8.0`（前序重构里程碑）**：完成异形盘格 2048 滑动合成、独立揉面补料、配餐托盘组合上菜（**纯上菜唯一得分**）、3 章 30 关地图与微信云开发双排行榜全量重构；
  - **`v0.9.0`（现行已落地代码基线）**：内测经济收支重平衡（`5,650 ⭐` 小铺总上限、前 3 章 `~56%` 毕业留白承接后续新章节）、厨余篮 `8.0s` 冷却与浪费惩罚、重塑「挑拣移位叉」5 模式空间调度及长线扩展底座加固；
  - **`v1.0.0`（规划正式首发版）**：完成真机打磨后首次向微信公众平台提审发布版本。
- **内部技术标识约定**：存档字段 `schemaVersion: 2`、测试脚本 `scripts/test_v2_core.mjs` 与资源名 `title_hero_v2.jpg` 代表“第 2 代核心玩法数据/资产结构”；全部现行文档已归整至 `docs/` 主目录，早期物理原型归档至 `docs/archive/`。
