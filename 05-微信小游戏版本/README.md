# 星夜吃茶 · 喵呜甜品合合乐 (微信小游戏原生版本)

本目录为 **原生 Canvas 2D 微信小游戏 (`compileType: "game"`)** 工程，零 HTML/DOM/CSS 依赖、零第三方引擎冗余体积，完整实现「星夜吃茶 3.0 魔改 Plan B」核心玩法与系统：

- **三大人气模式**：主厨订单模式、90 秒限时狂欢（含「星风救急」溢罐吹散不秒死与局内全额星尘结算）、悠闲经典模式。
- **茶馆大堂 & 看板互动**：支持点击戳戳看板娘气泡语音、3 位看板娘切换（蜜柑 / 露娜 / 小麦）、看板专属被动加成、甜品屋红点提示。
- **星夜甜品屋**：永久升级道具（初始彩虹 / 暴击倍增 / 狂热延长 / 道具补给）、3 款玻璃罐主题皮肤（琥珀 / 樱雪 / 月光）、3 位看板娘解锁，使用 `wx.getStorageSync` / `wx.setStorageSync` 本地持久化。
- **奇遇事件 & 物理系统**：星尘流星雨、捣蛋毛线球刚体（HP=2 邻近合成或摇一摇震碎）、喵呜祈愿风铃（立即触发三选一主厨祝福），多边形复合刚体物理 + 随机下落旋转倾角。
- **微信小游戏原生适配**：
  - 顶部栏自动对齐并避让右上角微信胶囊按钮 (`wx.getMenuButtonBoundingClientRect()`) 与异形屏安全区 (`safeArea`)。
  - 原生 `wx.createWebAudioContext()` 程序化双曲风音效与三路延迟混响兼容。
  - 支持 `wx.vibrateShort` 震动反馈、前后台切入音频自动静音 (`wx.onShow` / `wx.onHide`) 与转发分享 (`wx.showShareMenu` / `wx.onShareAppMessage`)。
- **极简包体**：全量 37 个量化 PNG/JPG 资源仅约 **1.28 MB**（含代码总计远低于微信小游戏 4 MB 主包上限），无需联网、零外部请求。

## 一、如何导入并预览体验

### 1. 打开微信开发者工具
1. 下载并安装官方 **[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)**（稳定版即可）。
2. 启动后选择 **「小游戏」** → **「导入项目」**。

### 2. 配置项目目录与 AppID
- **项目目录**：选择本仓库下的 `05-微信小游戏版本` 文件夹（内部包含 [`game.json`](game.json) 与 [`project.config.json`](project.config.json)）。
- **AppID**：
  - **电脑模拟器快速试玩**：可直接使用项目已预填的测试号 / 游客模式 (`touristappid`)，无需注册即可在模拟器跑通全部玩法。
  - **手机微信扫码真机预览 / 上传体验版**：在 [微信公众平台](https://mp.weixin.qq.com/) 注册个人小游戏并填入你自己的正式 AppID（也可使用公众平台「小游戏测试号」扫码预览）。

### 3. 模拟器试玩与真机扫码
- **模拟器试玩**：导入后即可在左侧画布中直接体验大厅、甜品屋、三模式、物理掉落与音效（右上角已预留微信胶囊安全位置）。
- **真机预览**：填写个人 AppID / 测试号后，点击工具栏 **「预览」** 生成二维码，使用手机微信扫一扫即可直接真机试玩，验证真机触控瞄准（上滑罐口外取消松手）、震动反馈与刘海屏安全区。
- **模拟器调试快捷键**：
  - 鼠标移动 / 拖拽控制掉落位置，松手下落；鼠标滚轮或 `W`/`S`/`↑`/`↓` 调整下落倾角，`R` 复位倾角
  - `←`/`→` 或 `A`/`D` 移动落点，`Space` / `Enter` 下落，`C` / `Shift` 暂存甜品
  - `M` 切换 BGM 风格，`P` 开关物理碰撞线框调试视图

## 二、目录结构

```text
05-微信小游戏版本/
├── game.json              # 小游戏竖屏与设备方向配置
├── project.config.json    # 微信开发者工具工程配置 (compileType: "game")
├── game.js                # 小游戏入口脚本
├── wechat_avatar_144x144.png  # 微信小游戏头像图标 (144×144 PNG, 约 33.6 KB)
├── assets/                # 37 份 PNG/JPG 量化资源 (约 1.28 MB)
└── src/
    ├── platform.js        # wx.* API 与浏览器降级抽象层
    ├── constants.js       # 甜品阶梯、祝福、看板娘、商店与皮肤配置
    ├── physics_shapes.js  # 多边形碰撞体轮廓定义
    ├── physics.js         # SAT + Sequential Impulse 刚体物理引擎
    ├── audio.js           # 原生 WebAudio 程序化配乐与音效
    ├── ui_draw.js         # 纯 Canvas 2D 木质招牌 / 信纸 / 按钮绘制原语
    ├── jar_renderer.js    # 玻璃罐、毛线球、预警射线与粒子特效渲染
    ├── screens_ui.js      # 大堂与局内 HUD（含胶囊避让布局计算）
    ├── modals_ui.js       # 甜品屋 / 履历 / 攻略 / 图鉴 / 三选一 / 结算弹窗
    └── game_app.js        # 核心玩法、三模式循环、奇遇事件与输入状态机
```
