### 1.2 风味与镀金后缀机制（防卡死铁律）
自第 2 章起，烤盘上会出现特殊烘焙格，为滑入或停驻的猫饼附上额外风味属性 `flavor`（共 4 种状态）：
- `plain`（原味，无后缀，默认）
- `matcha`（抹茶洒粉：`🍵` 绿叶微标，第 2 章引入）
- `berry`（草莓果酱：`🍓` 粉心微标，第 3 章引入）
- `gold`（镀金烘焙：`✨` 金光边框，第 2 章引入，万能风味王牌）

#### 规则铁律（核心防卡死设计）：
1. **任意同阶皆可合并**：只要两颗猫饼的阶数 `tier` 相同（且 `tier < 7`、非冰封），**无论它们各自的 `flavor` 是原味、抹茶、草莓还是镀金，都能顺利合成 `tier + 1`！** 绝不出现“因为风味不同而不能合并”的阻塞体验。
2. **合并后风味继承优先级**：两颗同阶猫饼合并生成高一阶猫饼时，新猫饼按以下顺序决定 `flavor`：
   - 若目标格本身是特殊格（`G`/`M`/`B`），先按继承规则取优，再叠加目标格染色（详见下条染色表）；
   - 纯双球合并继承优先级：`gold`（最高，只要任一方是镀金，合成物直接为 `gold`） > **停留在特殊格上的风味 / 移动方非原味风味** > **被撞方非原味风味** > `plain`。
   - 若 `matcha` 与 `berry` 两颗不同风味猫饼合并（无 `gold` 参与），则继承**主动移动方（Moving Tile）**的风味（若移动方为 `plain` 而静止方有风味，则继承静止方风味）。
3. **风味对上菜的匹配规则**：
   - 当顾客订单某槽位要求 **不限风味**（`flavor: 'any'`）时：任意风味的同阶猫饼都能匹配；若恰好放入 `gold` 猫饼，该单品仍享受 `×1.50` 镀金加价！
   - 当顾客订单某槽位要求 **指定风味**（如 `C4[matcha]` 抹茶蜂蜜布丁）时：仅接受 `flavor === 'matcha'` **或万能王牌 `flavor === 'gold'`** 的该阶猫饼；原味或其他风味不能顶替（避免托盘误吞导致无法凑单；点击盘格中风味不符的猫饼若场上无人需求会弹出轻量提示，但仍允许玩家主动点击搬出腾格）。

## 2. 异形盘格 2048 滑动合成与补料机制

### 2.1 异形盘格类型表
每关烤盘基于 `3×3` 到 `5×5` 的逻辑网格裁剪而成，支持以下 7 种单元格属性：

| 编码 | 格类型 | 出现章节 | 物理与交互行为 |
| :-: | :--- | :---: | :--- |
| `.` | 普通烘焙格 | 全章节 | 可承载猫饼，正常通行与合并 |
| `#` | 缺角 / 虚空 | 全章节 | 不存在物理格位，构成 L 形、十字、缺角星盘等异形边界，**阻断滑动穿行** |
| `X` | 木质障碍柱 | 1-8 起 | 占格实体障碍物，不可放猫饼，**将所在行/列切割为两段各自独立的 2048 滑道** |
| `G` | 镀金烘焙格 | 第 2 章起 | 猫饼滑经并停留在 `G` 格，或在 `G` 格上完成合成时，立即获得 `gold` 镀金状态（一次性整局有效该格永久存在，可反复用来镀金不同猫饼） |
| `M` | 抹茶洒粉格 | 第 2 章起 | 猫饼停留在 `M` 格或于此合成时，若当前非 `gold`，则染为 `matcha` 风味（`gold` 不会被覆盖降级） |
| `B` | 草莓果酱格 | 第 3 章起 | 猫饼停留在 `B` 格或于此合成时，若当前非 `gold`，则染为 `berry` 风味 |
| `I` | 冰封起始格 | 第 3 章起 | 仅在开局生效的冰壳状态（底层仍是 `.` 普通格）。被冰封的猫饼（`frozenHp = 1`）：**不可参与滑动移动、不可被直接合并、不可点击装入托盘**；当其**正上下左右 4 个相邻格中任意格发生一次合成**（或使用清格叉/蜂蜜柴柴主动技）时，冰壳碎裂恢复为普通可操作猫饼（**破冰本身 0 分**，释放的高阶原料即为奖励） |

### 2.2 四向滑动规则（异形分段 2048）
玩家在烤盘区域向上、下、左、右滑动（或桌面端按下方向键 / WASD）：
1. **分段扫描**：沿滑动反方向逐行或逐列扫描，遇到 `#` 缺角、障碍柱 `X` 或当前仍处于 `frozenHp > 0` 的冰封格时，视为**硬墙断点**，将该行/列切分成若干连续普通格片段。
2. **单段压缩与合并（经典 2048 单步防连合规则）**：
   - 在每个连续片段内，所有非空且未冰封的猫饼向滑动方向紧缩；
   - 从靠墙端开始依次比较相邻两颗猫饼：若 `tier` 相同且 `tier < 7`，则合并为一颗 `tier + 1` 的新猫饼，并标记本步已合并；**同一颗新合出的猫饼在本轮滑动中不再继续与下一颗同阶连续合并**（例如同一段内 `[C1, C1, C2]` 向左滑结果为 `[C2, C2]`，不会直接变成 `[C3]`；`[C1, C1, C1, C1]` 向左滑结果为 `[C2, C2]`）。
3. **有效滑动判定与自动刷饼**：
   - 若本次滑动导致至少 1 颗猫饼位置发生变化，或发生至少 1 次合成，则判定为**有效滑动**；
   - **每次有效滑动完成后**：系统立即从当前所有**空白可用格（`.`/`G`/`M`/`B` 且无猫饼）**中均匀随机挑选 `1` 格，生成 `1` 颗低阶猫饼（基础 `90%` 为 `C1`，`10%` 为 `C2`；受「精选猫饼粉」设备与「眠眠星兔」被动提高 `C2` 比例，最高可达 `43%`）；
   - 若新生成的猫饼恰好落在了 `G`/`M`/`B` 特殊格上，立即自动染色。
   - **无效滑动**：若盘格内没有任何一颗猫饼能移动或合并，视为无效滑动，播放轻柔撞墙闷响并微颤提示，**不刷出新猫饼**。
4. **合成的纯正向价值**：每次合成产生 Q 弹光效、邻近冰封格破冰（若触发），并且合出 **`≥ C5` 猫饼**时额外回复主厨搭档 **`+8%` 主动技充能**；但**所有合成均不加 1 分**。

### 2.3 底部独立「揉面补料」按钮
在烤盘正下方居中放置超大视觉焦点按钮——**「🐾 揉面补料」**：
- **交互**：无冷却或极短防抖冷却（`0.12s`），玩家在营业倒计时内随时可以点击；
- **效果**：在当前盘格所有空白可用格中随机挑选 `1` 格，投放 `1` 颗低阶猫饼（与滑动刷新同分布：`C1` / `C2`，若落入特殊格同样立即染色）；
- **战略意义**：
  1. **急单救火**：顾客只要 1 颗 `C1` 或只差 1 颗 `C1` 凑成 `C2/C3` 时，无需打乱已经排好的大饼阵型来滑动，直接点「补料」瞬间出原料上菜；
  2. **主动压盘博弈**：想快速攒大饼冲 VIP 单时连续补料+滑动，但过快补料会迅速挤占异形盘格空间，迫使玩家必须及时通过托盘上菜消格，形成《飞机大厨》般的紧张快感！
- **满格状态**：若当前盘格已无任何空格，点击「补料」提示“烤盘已满，请先上菜或滑合并腾格！”。

## 3. 配餐托盘（3~4 格）与单击组合上菜系统

### 3.1 盘格 → 托盘的单向装盘规则
在吧台顾客区与异形烤盘之间，横置一条**「配餐托盘（Serving Tray）」**，初始拥有 **`3` 个托盘槽**（在吃茶小铺升级「宽大木托盘」Lv.1 后扩充至 **`4` 个托盘槽**）：
1. **需求实时高亮**：系统实时扫描场上所有在座顾客的未完成菜单需求，凡是烤盘内存在**满足任一位在座顾客当前需求**的非冰封猫饼，该猫饼外圈自动亮起**暖金呼吸提示圈**，让玩家在忙碌滑动中一眼锁定可端走的菜。
2. **单击装盘消格**：
   - 在烤盘上**轻点（单击）**任意一颗非冰封猫饼（无论是否被顾客高亮，均可装盘腾格）：
   - 若配餐托盘仍有空槽：该猫饼**立刻从异形盘格中移除（瞬间腾出一个珍贵烤盘空格）**，以 `0.16s` 轻快弧线飞入托盘最左侧空槽；
   - 若配餐托盘已满（3/3 或 4/4）：烤盘单击不移除猫饼，托盘外框闪红提示“托盘已满，请先上菜或双击丢弃”。

### 3.2 托盘组合自动匹配与一键上菜机制
只要配餐托盘内的猫饼集合发生变化，系统立即自动检测是否已凑齐某位在座顾客的整份套餐：
1. **自动上菜（默认极速手感）**：
   - 当托盘内现存猫饼的**多重集合（含阶数与风味校验）**完整包含某位顾客的全部所需菜单（例如顾客点「午茶双拼：`C2 + C3`」，而托盘里有 `[C2, C4, C3]`）：
   - 无需额外再点一次顾客，系统延迟 `0.10s`（留出飞入视觉收尾）**自动把对应的 `C2` 与 `C3` 从托盘端出飞向该顾客**，剩余的 `C4` 继续稳稳留在托盘里等待凑下一桌！
2. **多桌同时满足时的匹配优先级**：
   - 优先服务被玩家点头像**手动锁定的目标顾客**（若存在）；
   - 其次优先服务**当前剩余耐心百分比最低**的顾客（救场优先，防止跑单）；
   - 若耐心相近（差距 `< 10%`），优先服务 **VIP 评委 / 急单狐狸**。
3. **顾客上点击直交互（辅助快捷）**：
   - 当多名顾客在座且托盘已凑齐某一位时虽然会自动端上，但玩家也可以先轻点某位顾客的订单卡，为其挂上「🎯 优先出餐」框；若玩家在托盘未满时点击某位顾客卡片，系统会清晰弹窗/高亮提示她还缺哪几颗猫饼。

### 3.3 托盘误放与「厨余桶」轻惩罚、死盘自救闭环
借鉴《飞机大厨》最经典的托盘管理机制：
1. **双击托盘丢弃进厨余桶**：
   - 如果玩家手滑把不需要的猫饼点进了托盘，或者因某位顾客耐心耗尽离开导致托盘里剩下了无人要的猫饼：
   - **双击（或长按/拖向右侧）托盘中的任意单个槽位**，该猫饼立刻飞入托盘右侧的**「🗑️ 厨余篮」**并销毁腾出托盘格；
   - **轻惩罚原则**：丢弃不扣已有分数，仅损失这颗猫饼原料与你此前花在它身上的操作时间（影响冲星节奏）。
2. **烤盘死锁自救闭环（Deadlock Recovery）**：
   - 当异形烤盘塞满且四向均无可合并对时，玩家永远拥有 **3 条零卡死出路**：
     - **路 1（最常用）**：直接单击烤盘里能凑单的猫饼装进托盘上菜消格；
     - **路 2（无工具也能自救）**：若托盘空余且盘满卡死，可单击烤盘内挡路的低阶废饼装入托盘 → 再双击托盘丢进厨余桶，即刻在烤盘里腾出 1~3 个空格重新盘活 2048！
     - **路 3（应急厨具）**：使用「🫧 泡泡清格叉」直接消掉挡路格，或用「✨ 升阶魔法勺」强行点升 1 颗促成连锁。

## 4. 实时客流、《飞机大厨》节奏与纯上菜计分

### 4.1 营业倒计时与 3 席位客流波次
每关设有固定营业时长（`90s ~ 150s`），吧台上方始终有 **3 个顾客座位（左、中、右）**：
1. **入座节奏与波次曲线**：
   - 开局 `0.5s` 内第 1、2 位顾客同时入座（第 `3s` 第 3 位入座，开局不冷场）；
   - 任一座位完成上菜或生气离开后，经过 `1.2s ~ 2.2s` 换台冷却迎来下一位新顾客；
   - **Rush Hour（高峰客流期）**：营业中后段（剩余时间 `55% ~ 15%` 区间）换台间隔缩至 `0.8s`，且更高概率出现双拼/三拼套餐与 VIP / 急单顾客，是冲 3 星的黄金爆发期；
   - **打烊收尾保护（最后 8 秒）**：剩余营业时间 `< 8.0s` 时不再生成新顾客（正在座位上的顾客仍可继续服务直到时间归零），避免玩家刚看到新订单根本来不及搓就打烊的挫败感。
2. **防卡死动态点单池**：
   - 顾客点单严格从**本关已配置菜单池**中抽取，并与当前烤盘生态联动：同一时间场上 3 位顾客中，**至少保证有 1 位顾客点的是 `≤ 当前盘面最高阶`（或 1~2 步即可合出）的亲民组合**，绝不会出现 3 个座全点高难三拼蛋糕的死局。

### 4.3 耐心三段小费、连击 Combo 与星光热潮（Fever）
1. **三段耐心条**：
   - 每位顾客从入座起拥有 `22s ~ 36s` 基准耐心（随订单品数增减，并受「暖心红茶壶」设备加成）：
   - **绿色愉悦段（剩余耐心 `> 55%`）**：急速上菜小费倍率 **`×1.30`**；
   - **黄色等待段（剩余耐心 `25% ~ 55%`）**：标准营业额 **`×1.00`**；
   - **红色焦躁段（剩余耐心 `< 25%`）**：顾客头像冒汗抖动，倍率降至 **`×0.85`**；
   - **耐心归零（`0%`）**：顾客摇摇头生气离开，**不扣已有总分**，但**清空当前上菜连击（Combo 归 0）** 并白白损失该单高分。
2. **上菜连击（Serve Combo）**：
   - 设置 **`10.0s` 连击窗口**：每次成功上菜刷新窗口并使连击数 `+1`（1连 `×1.00` → 2连 `×1.10` → 3连 `×1.22` → 4连 `×1.35` → 5连及以上封顶 **`×1.50`**）；超时或发生跑单则连击清零。
3. **星光热潮（Starlight Fever）**：
   - 能量槽仅通过**成功上菜**积攒（普通单 `+20%`、绿条急速上菜 `+25%`、VIP 单 `+35%`）；
   - 攒满 `100%` 自动开启 **`10.0s` 星光热潮**：期间所有**上菜得分 `×1.35`**，且全座顾客**耐心流逝速度减半（`×0.5`）**，全屏闪烁暖金星火氛围光！

### 4.4 全局唯一铁律：纯上菜得分公式
> **铁律**：2.0 版本中，`addScore` 仅能在 **“顾客整单上齐结账”** 这唯一入口被调用。以下行为**严格计 0 分**：滑动合并猫饼、点击补料、破冰、单击猫饼装入托盘、双击丢进厨余桶、使用清格叉/升阶勺、释放搭档主动技。

```text
单次上菜得分 = round(
    Σ(单品基础菜价(tier, catcakeUpgradeLv) × 单品风味镀金倍率)
  × 套餐组合倍率       // 1品=1.00 | 2品=1.18 | 3品=1.35
  × 耐心小费倍率       // 绿(>55%)=1.30 | 黄(25%~55%)=1.00 | 红(<25%)=0.85
  × 上菜连击倍率       // 1连=1.00 | 2连=1.10 | 3连=1.22 | 4连=1.35 | 5连+=1.50
  × 顾客类型倍率       // 普通=1.00 | 焦糖小狐狸=1.25 | 星冠美食家VIP=1.50
  × 搭档与设备杂项加成 // 含小蜜柑被动(×1.08)、兔技爆发(×1.50)、柴柴3连(+0.10)、宽托盘Lv2 3品(+0.12)
  × 热潮倍率           // 非热潮=1.00 | 星光热潮=1.35
)
```
- **单品风味镀金倍率**：
  - `gold` 镀金猫饼：**`1.50`**（即使该槽位不限风味也加价 50%）；
  - 当订单指定风味（`matcha` 或 `berry`）且匹配成功：**`1.35`**；
  - 其余普通匹配：**`1.00`**。

## 6. 关卡制与吃茶小铺长线成长

### 6.1 3 大章节 × 30 关进度与星级评定
- **章节结构**：
  - **第 1 章《街角星夜店》（1-1 ~ 1-10）**：默认开启，教学与基础异形盘格。
  - **第 2 章《樱花露台店》（2-1 ~ 2-10）**：通关 `1-10` **且总星数 `>= 18 ⭐`** 解锁，新增 `C6`、镀金格 `G`、抹茶格 `M`、VIP 评委。
  - **第 3 章《月光天台店》（3-1 ~ 3-10）**：通关 `2-10` **且总星数 `>= 40 ⭐`** 解锁，新增 `C7`、草莓格 `B`、冰封格 `I`、双风味套餐。
- **过关与评星标准**：
  - 倒计时归零后进入打烊结算：`总上菜分 >= star1` 即算**过关（解锁下一关）**；依据分数点亮 **1 星 / 2 星 / 3 星**。
  - **星尘产出**：
    1. **首星突破奖**（每关每星仅领 1 次）：第 1/2/3 星分别奖励 `15/20/30 ⭐`（第 2 章 `20/25/35 ⭐`，第 3 章 `25/35/45 ⭐`）；
