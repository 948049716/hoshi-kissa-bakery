## 3. L2 · 30 关配置静态压测规范

校验脚本遍历 `levels_data.js` 全部关卡时，逐关强制断言以下 6 条不变量：
1. **数量完备与动态星数一致**：每章精确 `10` 关连续不缺失，`MAX_CAMPAIGN_STARS === LEVELS.length * 3`。
2. **矩阵矩形对齐与字符合法性**：`matrix` 每行等长，且仅包含 `.` `#` `X` `G` `M` `B` `I`。
3. **预置坐标合法性**：`presets` 均在界内且非 `#`/`X`；凡 `I` 格必有 `frozen: true` 预置，非 `I` 格无冰封。
4. **可达性与连通性校验**：每关非冰封可滑格 `>= 8`，且 BFS 检查无 `1` 格孤岛死牢。
5. **星级分严格递增与章节机关约束**：`0 < stars[0] < stars[1] < stars[2]`，第 1 章不含 `M/B/I`，第 2 章不含 `B/I`。
6. **云端反作弊安全裕度**：每关 `stars[2]` 必须留有充足倍率余量低于服务端对应章节单关分数上限（`35k / 90k / 220k`）。

## 4. L3 · `scripts/verify_minigame_e2e.mjs` 核心端到端验收场景

1. **首屏大厅与版本基线校验**：启动即呈现选关大厅，新档初始星尘为 **`15 ⭐`**，无旧版残余模式按钮。
2. **开局进关与纯上菜零分断言**：进入 `1-1`，执行有效 2048 滑动与「揉面补料」，断言猫饼正常合成刷出且 **`score === 0`**。
3. **单击装盘、点客上菜与唯一加分断言**：单击亮金圈猫饼飞入托盘，凑齐整单后顾客发光，点击该顾客上菜后 `score > 0`、`ordersServed >= 1`。
4. **厨余篮 8s 冷却与挑拣移位叉解围**：双击托盘丢弃触发 `8s` 冷却遮罩并拦截连续第 2 次丢弃；激活「挑拣移位叉」完成跨格挪移/合并或直投厨余救急，全程 `score` 不变。
5. **时间推进、星级结算与重刷衰减**：通关结算点亮星级、发放首星星尘并持久化解锁 `1-2`；同星重刷验证衰减收益。
6. **吃茶小铺关卡门控与消费生效**：验证未解锁关卡的高阶猫饼（如 `C6/C7`）显示置灰门控不可越级购买；通关攒够星尘升级 `C1 Lv.1`（`25⭐`）与 `宽大木托盘 Lv.1`（`75⭐`）后重载验证托盘扩至 **`4` 格**且 `C1` 基础价升至 **`35`**。
7. **多视口胶囊避让与弹窗自适应滚动**：在 `375×667`、`390×844`、`1280×760` 下验证零胶囊重叠、零安全区越界及小铺/图鉴平滑滚动。
8. **零运行时异常与包体红线**：全程 `0` `console.error`、`0` `hsl()` 渐变违规、`0` 原生彩色 Emoji、主包原始体积 `<= 3.5 MB`（v0.10 起上调，严守微信 `< 4 MB` 红线）。
